## Checklist item (verbatim)

> Adequate fire flow is available for the worst-case building on the Site Plan, using the total building fire area unless the building is separated by fire walls with no openings constructed per the IBC.

**Evidence expected**: Fire flow calculations / water plan

## Agent observation (verbatim)

> Sheet 1 (Cover Sheet), Block 6 (Austin Fire Department table) lists Fire Flow Demand @ 20 PSI = 5,000 GPM and enumerates building fire areas including Fire Area 1-A: 107,056 SF, Fire Area 1-B: 107,078 SF (largest), Fire Area 1-C: 46,655 SF, Fire Area 2-A: 86,675 SF, and Garage: 211,600 SF. Sheet 6 (Austin Water General Information) confirms Building Size = 116,166 SF (largest building), Building Type = Type IIIA per IFC Table B105.1(2), and Available Fire Flow = 8,156 GPM at 20 PSI, which exceeds the required 5,000 GPM.

## Agent reasoning (verbatim)

> IFC 507.1 & Appendix B require fire flow to be determined based on the total building fire area of the worst-case building. The U1 plan identifies the largest fire area (107,078 SF) and states the required fire flow (5,000 GPM) derived from that area. The available supply (8,156 GPM) exceeds the requirement. This satisfies the code requirement for adequate fire flow using the total building fire area unless separated by fire walls with no openings per IBC.

## Agent explanation (verbatim)

> Fire flow 5,000 GPM determined from worst-case fire area 107,078 SF; available flow 8,156 GPM exceeds requirement.

- Sheet 6: Austin Water General Information - fire flow calculations

## Hypothesis — why the agent got this wrong

Agent verified the values are *stated* on the cover sheet — fire flow demand 5,000 GPM and available 8,156 GPM. Did not check the underlying calculation that derives 5,000 GPM from the 107,078 SF worst-case area (IFC Appendix B lookup) and did not confirm fire walls / openings condition.
