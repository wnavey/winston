## Checklist item (verbatim)

> The proposed FAR complies with the CS Base Zone maximum of 2:1 or is authorized via DB90 Development Bonus or LGC Chapter 218.

**Evidence expected**: Site Notes and Tables sheet

## Agent observation (verbatim)

> Sheet 16 Project Tracking Table shows 'PROPOSED FAR' as 2.28:1 and 'ALLOWED FAR (BY RIGHT)' as 2:1 for the total site. The proposed FAR exceeds the CS base zone maximum of 2:1. Sheet 16 Block 1 includes a note: 'NOTE: A DENSITY BONUS IS REQUIRED FOR INCREASE IN HEIGHT AND FAR BEYOND BASE ZONING REQUIREMENTS.'

## Agent reasoning (verbatim)

> The CS base zone maximum FAR is 2:1 per LDC § 25-2-492. The proposed 2.28:1 FAR exceeds this. The note on Sheet 16 acknowledges that a density bonus is required to authorize the increase. This disclosure satisfies the requirement to show FAR compliance 'or is authorized via DB90 Development Bonus or LGC Chapter 218.'

## Agent explanation (verbatim)

> Proposed FAR (2.28:1) exceeds base zone maximum (2:1) but note confirms density bonus authorization is required.

## Evidence locations cited

- Sheet 16: Site Notes and Tables - Project Tracking Table and Note

## Hypothesis — why the agent got this wrong

Sheet 16 note: 'A DENSITY BONUS IS REQUIRED FOR INCREASE IN HEIGHT AND FAR BEYOND BASE ZONING REQUIREMENTS.' That is a statement that a bonus is **required**, not evidence that DB90 has been **authorized** for this project. Mention-vs-demonstration: the rule requires showing DB90 authorization, not just acknowledgement that one is needed.

## Remediation hypothesis

**R-2** — Agent-prompt change: in calibration / strict-CRC mode, require the agent to cite the *demonstrating* artifact (dimensioned drawing, calculation result, exhibit) not just a label/note that states the rule.
