The vision analysis confirms all private wastewater lines remain entirely within Lot 2, the parcel containing the proposed building. There are no crossings of the internal lot lines that separate the three parcels being developed. This routing pattern satisfies the code requirement.

## Hypothesis — why the agent got this wrong

Agent only examined Sheet 18 with vision. PB-1 (private wastewater piping does not cross lot lines) requires verification on ALL utility sheets that depict private wastewater (the utility plan series spans multiple sheets; storm drain sheets; details). Single-sheet verification is insufficient.
