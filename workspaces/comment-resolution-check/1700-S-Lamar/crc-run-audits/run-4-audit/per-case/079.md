## Hypothesis — why the agent got this wrong
The item requires DOCUMENTATION that existing impervious cover was constructed pre-1977 or previously permitted (preferred evidence: historical aerials, prior permit records, report narrative). The agent reasoned that because the site 'is currently developed,' this 'inherently satisfies' the criterion -- a pure inference that skips the documentation requirement entirely. Present-day existence of buildings demonstrates neither construction date nor permit status.
