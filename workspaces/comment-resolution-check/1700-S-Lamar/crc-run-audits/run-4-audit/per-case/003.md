## Hypothesis — why the agent got this wrong
The majority conflated storm-drain (DPW) standard details with Austin Water details. Its own observation lists Curb Inlet, Precast Inlets/Junction Boxes, Trench Drain, and Storm Pipe Connection details on Sheet 36 and labels them all 'AW details' -- those are DPW/storm standards (the dissenting run correctly identified DPW standard 508S-3 mixed onto the AW sheet). Because the agent lacked a discipline taxonomy for standard-detail numbering (###-AW-## vs 5xxS-x storm series), it treated everything on the 'Utility Details' sheets as AW by association with the sheet title, so the interspersion the item targets was invisible to it.
