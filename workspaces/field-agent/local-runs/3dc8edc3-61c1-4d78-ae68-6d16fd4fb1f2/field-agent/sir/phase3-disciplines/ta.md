# Transportation Findings — 12713 Cinchring Ln

**Property:** 12713 Cinchring Ln, Austin, TX 78727 — Lot 12, Block M, Scofield Subdivision
**Proposed use:** Demolish existing SFR; build ground-up duplex (2 units)
**Lot:** ~7,840 sq ft (0.18 acres), SF-2 zoning
**Frontage:** Cinchring Ln (ASMP Level 1, local residential, City of Austin)

---

## Summary

- **No Traffic Impact Analysis (TIA) required.** The duplex generates approximately 10 net new daily trips, far below Austin's 2,000-trip TIA threshold. No TIA Determination Worksheet filing is necessary.
- **No ROW dedication anticipated.** Cinchring Ln is an ASMP Level 1 street with a 50-ft ROW standard; the existing platted ROW already meets this width, so no dedication delta exists.
- **Driveway permit required.** Demolition of the existing concrete drive and construction of a new driveway serving the duplex will require a driveway permit under TCM Section 7.
- **Sidewalk construction or fee-in-lieu likely required.** Austin requires a minimum 5-ft sidewalk along frontage on Level 1 streets. Existing sidewalk conditions on Cinchring Ln should be confirmed; if absent or substandard, the developer must construct or pay fee-in-lieu per LDC Section 25-6-354.
- **No scenic roadway, Hill Country Roadway, or Project Connect overlay constraints apply.** The site is well outside all designated scenic corridors, Hill Country Roadway corridors, and Project Connect rail reservation areas.

## Findings

### 1. TIA Not Required

| Field | Detail |
|---|---|
| **Severity** | `note` |
| **Citation** | LDC Section 25-6-111 through 25-6-117; TCM Section 10; TIA Guidelines Section 2 |
| **Finding** | The project replaces one single-family unit with a duplex (2 units), yielding a net increase of approximately 1 unit and roughly 9-10 net new daily trips (ITE Land Use 210/220, ~9.4 trips/unit). The TIA threshold is 2,000 unadjusted daily trips. The project is orders of magnitude below this threshold. The Neighborhood Traffic Analysis (NTA) trigger of 300 net new daily trips on a residential street is also not met. |
| **Implication** | No TIA, Transportation Assessment, TDM Plan, or NTA is required. No TDS coordination is needed for traffic study purposes. |
| **Recommended next step** | None required. No TIA Determination Worksheet filing necessary for a project of this scale. |

### 2. No ROW Dedication Required

| Field | Detail |
|---|---|
| **Severity** | `note` |
| **Citation** | LDC Section 25-6-51, 25-6-54; ASMP Street Network Table; TCM Section 2 |
| **Finding** | Cinchring Ln is classified as ASMP Level 1 with a 50-ft ROW standard. The existing platted ROW in the Scofield Subdivision meets this 50-ft standard. The dedication delta is zero. No street deed or plat-based dedication is anticipated. |
| **Implication** | The developer retains the full existing lot area; no buildable area is lost to future ROW dedication. Setbacks are measured from the existing property line. |
| **Recommended next step** | Confirm existing ROW width against the survey at site plan review. If any discrepancy is identified, the City would require dedication along the frontage as a condition of approval. |

### 3. Driveway Permit Required

| Field | Detail |
|---|---|
| **Severity** | `moderate` |
| **Citation** | TCM Section 7 (Driveways), specifically 7.3.1 (driveway types), 7.5.1.2 (width), 7.6 (spacing) |
| **Finding** | The existing concrete driveway will be demolished with the house. A new driveway serving the duplex must be permitted under TCM Section 7. On a Level 1 street, a Type I (residential) driveway is permitted. Maximum width is typically 20-24 ft for a two-way residential driveway. A single shared driveway serving both duplex units is the standard configuration and satisfies all spacing requirements. Minimum 30-ft setback from the nearest cross-street curb return applies. |
| **Implication** | The driveway permit is a standard requirement but must be coordinated with the building permit timeline. Driveway location must not conflict with TCM spacing standards or the existing 5-ft PUE along the lot line. |
| **Recommended next step** | Submit driveway permit application concurrent with building permit. Confirm driveway location relative to any opposing driveways across Cinchring Ln and adjacent lot driveways for offset compliance. |

### 4. Sidewalk Obligation Along Frontage

| Field | Detail |
|---|---|
| **Severity** | `moderate` |
| **Citation** | LDC Section 25-6-354 (fee-in-lieu); TCM Section 4.1.6; LDE Residential Review Guidelines (rev. November 2025) |
| **Finding** | Austin requires a minimum 5-ft clear-width sidewalk along all street frontages for new residential development on Level 1 streets. Whether Cinchring Ln currently has a sidewalk along the project frontage is not confirmed in the available data. If a sidewalk exists and meets current standards, no action is needed beyond maintaining it. If absent or substandard, the developer must either construct a compliant sidewalk or, if physical constraints exist (trees, drainage, utilities), apply for fee-in-lieu under LDC Section 25-6-354. |
| **Implication** | Sidewalk construction adds modest cost and must be coordinated with driveway placement and the 5-ft PUE. If heritage or protected trees are present in the ROW, fee-in-lieu may be the more practical path. |
| **Recommended next step** | Conduct a site visit or review aerial imagery to confirm existing sidewalk conditions along the Cinchring Ln frontage. If sidewalk construction is required, incorporate it into the civil site plan. If obstructions exist, pursue fee-in-lieu early in the permitting process. |

### 5. Street Impact Fee Applies

| Field | Detail |
|---|---|
| **Severity** | `note` |
| **Citation** | LDC Section 25-6-662, 25-6-663(B) |
| **Finding** | Street Impact Fees (SIF) apply to virtually all building-permit development in Austin, independent of TIA status. SIF is assessed at plat or building permit application and collected at building permit issuance. For a net increase of one dwelling unit, the fee will be modest but must be accounted for in the project budget. |
| **Implication** | SIF is payable at building permit issuance, not at site plan approval. The required cover-sheet note referencing LDC 25-6-662 must appear on plans. |
| **Recommended next step** | Submit SIF Estimator Worksheet via ATD KNACK portal to obtain the formal calculation memo prior to building permit application. Budget for SIF in development pro forma. |

## Open Questions for the Engineer

1. **Existing sidewalk conditions:** Does a sidewalk currently exist along the project's Cinchring Ln frontage? If so, what is its width and condition? This determines whether new construction, reconstruction, or fee-in-lieu is the appropriate path.

2. **Driveway configuration:** Will the duplex use a single shared driveway or two separate driveways? Confirm proposed driveway location(s) relative to opposing driveways and adjacent lot driveways for TCM Section 7.6 offset compliance.

3. **Survey-confirmed ROW width:** The research assumes the existing platted ROW meets the 50-ft Level 1 standard. Has the boundary survey confirmed the ROW width along the Cinchring Ln frontage, or is this assumption based on plat records alone?

4. **Heritage/protected trees in ROW:** Are there any heritage or protected trees within the ROW or along the property frontage that could constrain sidewalk construction or driveway placement?

5. **SIF estimate:** Has the SIF Estimator Worksheet been submitted to obtain the formal calculation memo? The net-new-unit increment is small, but the fee amount should be confirmed for the pro forma.
