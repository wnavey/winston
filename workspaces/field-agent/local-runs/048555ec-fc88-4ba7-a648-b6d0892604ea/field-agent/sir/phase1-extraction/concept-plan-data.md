- Sheet 2 shows truck-turn simulation overlaid on the same site plan

- The truck-turn path shows a delivery vehicle entering from Cameron Rd, circulating through the site, and exiting
- The truck sweeps appear tight — the engineer's note suggests the current drive-aisle width may be marginal
- **Design vehicle:** Appears to be a standard delivery truck (SU-30 class based on turning radius); exact AASHTO designation not labeled
- The label "WB 61 — Articulated Semi-Trailer" may be visible on the path — this would be a WB-62/WB-67 design vehicle if the truck-turn is for delivery access
- **Key constraint:** The note indicates the aisle/maneuvering distance needs to be 35-40' for a comfortable truck turn; this affects the site layout south of the building

## Disagreements between extractors / discrepancies with intake

1. **Lot area:** Plan table shows 44,150 SF; intake states 44,250 SF — 100 SF difference. Use plan table value (survey-derived) as primary.
2. **Building coverage:** Plan shows 17%; intake states 16.7% — minor rounding. Plan value is consistent with 7,375 / 44,150 = 16.71%.
3. **Proposed IC:** Plan shows 16,666 SF / 37.75%; intake states 16,680 SF / 37.7% — minor discrepancy. Plan table value is primary.
4. **IC allotment:** Intake states 80% limit; plan table shows 95% column. The 80% likely refers to the watershed overlay IC limit, and 95% may be the base zoning CS IC limit. Both may apply with the more restrictive governing. Needs verification in Phase 2.
5. **Tree survey date:** Intake states December 30, 2020; plan note states December 30, 2025. The plan date is more recent and should govern.
