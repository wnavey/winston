02 · the nameThe name ruleThe prompt fragment, what it produces on real blocks, and the checks that enforce it.

A short noun phrase a drafter would use for the element: the printed heading when there is one, otherwise the drafter's name for what it is; 2–6 words, Title Case, never "Block N" (D2).

bureau/runbooks/lib/block-name-rule.md · included by Read 3 and by name-blocksname — a short noun phrase a plan reviewer would use to point at this element on the sheet. · 2–6 words, Title Case, no trailing period. · Use the element's PRINTED HEADING when it has one, as printed: "Sheet Index", "General Notes", "Legend", "Meter Notice", "Compatibility Setback Table", "Detail 3-A Valley Gutter", "Erosion Control Notes". · Otherwise use the drafter's name for what it is: "Engineer's Seal", "Surveyor's Certificate", "Site Plan Release Form", "Revision Table", "Vicinity Map", "Curve Table", "North Elevation", "Sheet Layout Key Map". · Never "Block N", never the sheet's own title, never a sentence, never our process words (block, crop, read, step, contract). A bare category word ("Notes", "Table") only when there is truly no heading and nothing better to call it. · Two blocks on one sheet may share a name only when they are genuinely the same kind of element ("General Notes" continued in a second column); otherwise qualify them ("General Notes 1–11", "General Notes 12–20").

Claim (§1.4): drafting practice and Austin's own reviewers name the element, not the position; position words are a renderer fallback, not stored.

05 · backfillThe name-blocks runbookWhy a partial v4 run cannot do it, the six steps, and the artifact patch.

v4 has no from-step or re-caption mode, every in-scope sheet gets all four reads from pixels on Opus with a 2 h budget, and staging existing blocks is barred by design under core rule 19 (§6.1).

A partial preprocessing-v4 run
Re-reads 1,655 sheet versions from pixels on Opus to add one field, and the stager refuses to show the reader the blocks it is meant to name (steps/1.2-stage/step.yaml:6-7). Not viable.
A bespoke name-blocks runbook
Reads the rows, names them with the same rule on a Sonnet-class model, validates, writes by id, patches the stored artifacts of registered runs. About 8 M input tokens for the corpus; under an hour at 10-wide fan-out.

Claim (D9): the backfill never touches boxes, descriptions or embeddings.
