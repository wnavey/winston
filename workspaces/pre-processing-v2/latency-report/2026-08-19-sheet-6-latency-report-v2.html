Where did the 72 minutes go?

Wall-clock anatomy of pre-processing one plan-set sheet (Sheet 6, 1700 S. Lamar) — the first run after the box-refine second pass landed. Reading 2026-08-19 · published 2026-08-24.

Reading a single value-bearing sheet at maximum fidelity took the orchestrator 71m44s of compute (telemetry: 4,304 s) — up from 57 min in the pre-box-refine run. The added time is entirely the new box-refine pass: a per-block zoom-and-correct sweep that ran 31m56s across 3 passes and 166 crops (~45% of the whole run) and relocated ~16 of 25 grossly-mislocated bounding boxes. It paid for itself but is now the single dominant cost. Meanwhile the image-cap bottleneck that cost the prior run an ~18-min forced re-pass did not recur — both readers completed cleanly. End-to-end system latency (kickoff → published, excluding the async human gate) was ~72.5 min; the deterministic publish was ~10 s.

Why box-refine cost 32 minutes — and whether it was worth it

1 · Box-refine is serial, per-block, and multi-pass

166 crop files across 3 passes over 25 blocks. Each block gets a clean crop + a blue-overlay crop rendered, a vision round-trip to correct the coordinates, then a deterministic remap — one block at a time. Pass-1 alone was 20m58s / 90 crops; passes 2–3 re-checked the blocks that hadn't converged. That serial zoom-render-read loop is the entire +32 min.

2 · It earned its keep — ~16 of 25 boxes were grossly mislocated

The first-pass eyeballed boxes weren't merely loose: a note box pointed at a neighbor, the PE-seal box sat off the seal, the Inspection-Notes box landed on the meter panels — individual corner moves up to ~231/1000 ≈ 23% of the sheet. Box-refine relocated and tightened them; 23/25 converged and the 2 that didn't grew deliberately to avoid a clip. On a dense form sheet, single-pass whole-sheet box eyeballing has a systematic placement weakness, and this pass is what closes it. The before/after overlay is in the run's hitl/ dir.

3 · The image-cap bottleneck did not recur

The prior run lost ~18 min to a forced Reader A2 pass after both readers hit a cumulative image cap and left the bottom-right unread. This run's readers both completed the whole sheet (Reader A 15:24, Reader B 15:17) with no A2 subdir and no re-pass — the bounded-crop mitigation held. That reclaimed roughly the time box-refine added.

4 · The quadrant-crop convenience renders were still wasted

The sheet-300-{NW,NE,SW,SE} quadrant renders all collapsed onto the same top-left region (an ImageMagick percentage-offset quirk), so every reader rendered its own crops instead. It cost no coverage (box-refine uses absolute-pixel geometry) but is pure wasted setup I/O. Filed as a one-line recipe fix in bureau#1159.

What this does (and doesn't) imply for scale

  • Box-refine is now the #1 lever on a value-bearing sheet. At ~45% of the run it dwarfs every other phase. Batching its per-block vision calls, or skipping passes 2–3 once a block converges, attacks the biggest slice directly.
  • Tier-gate box-refine like the adversarial pass. A pure-drawing sheet has few content blocks and loose boxes matter less; running the full 3-pass sweep on every sheet of a 45-sheet set would be the dominant cost of the whole set. Gate it to value-bearing sheets.
  • Sheets parallelize; a single sheet's passes do not. Everything after the two readers is a serial dependency chain (reconcile → box-refine → adversary → corrections). The 72 min is the depth of one hard sheet's chain, not a per-sheet multiplier — 45 sheets is not 45×72 min.
  • Don't linearly extrapolate. This is a value-bearing sheet read with the full triad, box-refine, and "tie-break up" fidelity. Most of a real set is cheaper pure-drawing sheets.
  • Human + deterministic cost is ~nil. The publish pipeline was ~10 s of real work; the human gate was async background-job wait, not latency. The only lever that matters is the reading compute — and within it, box-refine.

Suggested follow-ups (not yet decided)

  • Tier-gate box-refine (full 3-pass on value-bearing, light/none on pure-drawing).
  • Early-exit box-refine per block once it converges, instead of running fixed passes 2–3 over all blocks.
  • Batch box-refine's per-block vision reads where the API allows, to break the serial zoom loop.
  • Land bureau#1159 so the quadrant convenience crops stop being wasted setup I/O.
  • Instrument the runbook to emit real per-step timings (this report was reconstructed from file mtimes + one telemetry number).
