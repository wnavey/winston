CARTOGRAPHER · SIR-FREE ANCHORING

Anchoring without a SIR: a loose PDF from upload to the map

Architecture companion to DESIGN-SPEC.md (winston#309). Today anchor-geometry cannot run on a file nothing owns: the SIR supplies the request's identity, the target coordinate system, the fitting ring and the owner of every row it writes. This spec finds the county ring from the plan set's own text, takes the target coordinate system from the ring itself, lets geo and cartographer_anchors carry no owner, and shows the derivation on a new evidence page. North star P2a + P2b.

What a loose file carries, and what it does not

The extract run already captured the zone ("TEXAS CENTRAL ZONE / NAD 83") and the combined scale factor (1.0000327271). It did not capture a unit, printed coordinates, or a location: page 2's lettering is vector outlines with 641 characters of text, and there are no State Plane values on any of the 30 sheets. So the file is rung 3, fitToRing, and the county ring is the anchor (§1.2).

Already in the database, measured

A live TCAD fetch at the site returns one feature whose seven-point ring matches the plat's five courses to within 0.01° and whose area is 43,557.77 ft² against the plat's 43,560. The project's site_outline is vertex-identical to that fetch. The plat's legal description resolves to the same parcel by name; the City of Austin locator scores the address 100; the Census geocoder returns nothing (§1.5).

02 · how it worksTwo ladders and a gate

Everything new in the run happens inside 1.2 fetch, before any solver. First the parcel: page 1 names the county, which picks the layer; then an operator point, else the plat's legal description, else the address, and whatever is found must match the plat's stated area. Then the target coordinate system, which comes with the ring: the layer stores its parcels in a State Plane code and says so. The plat's zone only checks it. No county id is involved anywhere. The solver never sees any of this. It reads inputs/parcels.json, whose shape does not change.
