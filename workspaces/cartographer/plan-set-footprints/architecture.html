Cartographer · Plan-set footprints

Building footprints from plan sets — the first proposed feature through extract-geometry-v2 and anchor-geometry

How a site plan set gets its proposed building footprint read beside the lot, registered to the lot by the property line both are drawn on, stored as a traced, proposed figure, and carried onto the county grid by the anchor run that already exists — so PostGIS can say how far the building sits from each lot line.

Overview

One feature, one geometry type, one file. The extract runbook learns to classify a document and trace a building outline from the PDF's own vector paths; the sheet is registered to the lot the run already extracted; the figure is stored as traced and proposed; and the anchor runbook carries it onto the grid with no solver change (§1.1, §1.5).

What this slice is for

  1. The north star's plan-set half, started with the feature that pays most. The IG report ranks the building footprint second in demand across 134 geometric comments (51 A+B, 30 A-tier, the most of any layer), and it is one side of the headline question: how far is the proposed building from the recorded lot line. §1.1, sizing note
  2. The geometry is already in the PDF; the identity is what costs. A Civil 3D export writes every line as a vector path in page coordinates. On White Water the CAD layer names survived too (803 optional content groups; the building is JCE BASE|C-BLDG, one closed 55-vertex ring). On 2008 San Antonio nothing survived but stroke styles. The reader is layer-first with a style-and-vision fallback. §1.3, D4
  3. Code traces, an agent only picks. No agent produces a coordinate: the tracer lifts candidate outlines, draws each on a crop through the crop tool, and a vision worker says which one is the building. On a layered sheet that is a check on the ranker; on a layer-less sheet it is the one thing code cannot do. D4–D6
  4. The lot registers the sheet. The property line is drawn on every plan-view sheet and the run already reads its calls there as context evidence. Fitting the sheet's boundary linework to the extracted lot gives the sheet's scale and rotation without reading the title block: on sheet 12 exactly 1″ = 20′, −15.46°, 0.004 ft mean residual. §1.4, D7
  5. Recorded and proposed stay distinguishable all the way down. A new posture column on both tables, so a review query can say WHERE posture = 'proposed' and measure between the two. D10
  6. The next features are registry entries. Trees, curbs and driveways each add one entry and one survey paragraph, plus the seam each opens: lines and points for trees and curbs, the county join for driveways. D17–D18, §8

How it works

Three mechanisms carry the slice: a dumb, recorded classification of the document; a tracer that lifts outlines from vector paths and ranks them by layer name when a layer exists; and a free-scale registration of the sheet to the lot that is drawn on it. On sheet 12 the registration lands at exactly 1″ = 20′ with a 0.004 ft mean residual (§1.4, §2.1–§2.4).

template T2 · Stage + T8 · ranking ladder
