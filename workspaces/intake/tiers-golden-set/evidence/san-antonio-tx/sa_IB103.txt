Scope:

Electronic plan review (EPR) is available for the following permit types:

 Residential building permits: New one-and two-family dwellings and townhouses as defined by
  the International Residential Code as well as additions to existing residential
 Commercial building permits: New commercial structures; additions, interior remodels and
  first time finish outs; grading permits, site work permits, foundation permits; and shell permits
 Trade permits: Tree, and some mechanical, electrical, plumbing permits requiring plan review
 Fire system permits: Fire system permits (e.g., fire sprinkler, fire alarm, fire extinguishing
  suppression systems, hazardous material tanks, underground fire mains, etc.)

Best Practices for Electronic File Submittal Procedures

There are three types of documents to be aware of during file uploads and resubmittals. The type
of file determines how the Plan Room processes an uploaded file and makes it available to
reviewers. This is determined by the “Document Type” that is chosen during the upload. It is
important that each file be uploaded with the correct “Document Type” chosen. For a document
being uploaded that is not in the pull down list, chose “Other Document” and describe what is
being uploaded.

•   Construction Plans – full size drawing(s) - may be marked up and tracked by sheet title – must
    be indicated as a type of “Construction Plan” when uploading. ONLY upload full size
    construction drawings/plans as “Construction Plans” not other reports and documents.

•   All other file submittals– Two sub-types

    Documents - Those that can be marked up by reviewers – Must be PDF only

               Smoke Control Report
               Special Inspection Determination
               Specifications
               Storm Water Management Plan
               Fire Flow Test

    Attachments - All other reports, letters, affidavits, forms, etc. – Can by any file type – These
             are viewed by reviewers but NOT marked up.

Construction Plans and Other Documents/Attachments (reports, forms, letters, affidavits, etc.)

 File Format: Each construction plan set must be saved in PDF format. Construction plans may
  be submitted in one or more pdf files. The ePermitHub plan room will take all the
  construction plan sheets in one or more pdf files, combine them together, then separate and
  track each sheet by its title from the title block.

 Table of Contents It is recommended that a file for Construction Plans have a Table of
  Contents. The Plan Room will read the table of contents to obtain sheet titles if available. If
  there is no Table of Contents, the Plan Room reads the Title Block using character recognition.

 Sheet Titles: Each sheet number for full size Construction Plans should be named using the US
  National CAD Standards. Most important however, revised sheets submitted MUST use the
  same sheet number. The plan room tracks all sheets individually and will use the last sheet
  version when providing the stamped approved sheet. Plan Reviewers can compare versions
  of the same sheet if they have the same sheet title. The electronic plan review software looks
  in the title block to determine if a submitted sheet is a revision or a new sheet that has never
  been uploaded.

 File Quality: Scanned documents are not recommended as scanning degrades the quality of the
  image and creates noise for the plan review software. If you must scan documents, the
  resolution should not be less than 300 dpi (dots per inch). Plans submitted in an unacceptable
  or unreadable format will be rejected during the intake process.

 File Names:

    For Construction Documents files may be named with your firm’s file naming conventions.
    For other project documents such as checklists, reports, affidavits, engineering letters,
     forms and other supporting documents, the file name needs to be descriptive of what is in
     the pdf. For resubmittal documents or attachments, the Plan Review software does not
     track versions and keeps all previous uploaded files regardless of the name of the file.

 File Size: Each PDF file is limited to a maximum of 80MB. If your design files for each discipline
  exceeds 80 MB, please separate and identify them accordingly. Example; if the architectural
  file was 104 MB total, split it into two files ( for example: Architectural-1.pdf at 85 MB and
  Architectural-2.pdf at 19MB).

 Plan Set Size: There is no total size for all files submitted at one time through the Accela
  Customer Access portal. As long as any uploaded file is less than 80MB.




                                                                                        Page 3 of 14
 Scale and Orientation: Pages must all be properly “oriented. During submittal, the Plan Room
  software allows the applicant to rotate sheets prior to finishing uploading. Plan Reviewers have
  the option of rotating sheets also.

 File Security/Accessibility: Files cannot be password-protected or locked documents. The Plan
  Room software will not accept password protected or locked documents, or corrupt files.

Intake and Completeness Review

After the application submittal and file(s) upload, the DSD Intake Team will complete the intake
process and ensure the electronic submittal package is complete per governing information
bulletins and department guidance. If any files or required forms or letters are missing, the project
will be placed on hold and the applicant/owner will be notified. Customers will submit required
missing items using the Accela Customer Access portal, following the same guidelines.

Once the electronic plan review submittal package is deemed complete, Development Services
staff will issue an BuildSA application number and notify customers of plan review fees due. After
plan review fees are paid, Plans Examiners will be assigned plan reviews.

General Plan Review Process

An array of Plans Examiners will be assigned to conduct required discipline reviews based on the
scope of work. Plans Examiners will review electronic plans and other permit submittal documents
using the City’s electronic plan review software. Each Plans Examiner will either approve or may
create issues for their respective review. The review status will be updated in the City’s system of
record for plan review. If code issues are found, the Plans Examiner will create comment issues
and may mark up specific sheets or a document that can be viewed online and in real time through
the Accela Customer Access portal. See the Plan Review Process.

Permits and Approved Plans

When all reviews have been completed and approved, Development Services will notify the
customer that building permit fees are due and request the applicant pay for the permit. Fees can
be paid on-line using a credit card or escrow account. Once the permit fees are paid, the permits
are considered Active with Inspections Pending.

 The approved plans will be available in the Plan Room in the ACA portal under the Approved
  tab. The approved plans will consist of the latest version of each sheet and will include a City
  approval stamp. In some instances, the approved plans package sent by DSD may also include
  additional documentation such as notes to building inspectors. Plans are read and print only
  and no modifications or design changes can be made. Files of the type Documents and/or
  Attachments that were uploaded and reviewed are not stamped and sent back.

 The customer will be able to make as many printed copies as needed from the approved plan
  set.




                                                                                         Page 4 of 14
After permit issuance, Customers are required to provide one hard copy of the approved
construction plans at the project site for City Inspectors. The City would prefer the approved plans
be printed in color in order to assist the inspectors in quickly identifying key inspection items.

Post-Permit Issuance Revisions

After a permit has been issued, there may be circumstances necessitating revisions to construction
documents previously approved. In situations requiring approval of changes made after the permit has
been issued. Once a permit is issued a Revision button will be available in the ACA portal to upload revised
sheets. Each sheet should have the same title as the sheet in the approved set. Additional sheets never
before submitted may also be submitted for review if needed. The Plan Room software will continue to
track sheets by sheet number in the title block and provide the new approved sheet when post permit
reviews are approved.
