# Sheet 29 — Addressing Plan

Site plan showing building layouts and individual unit addresses.

## Reading Guide

This sheet contains the Addressing Plan for the Valley View Townhomes project, illustrating the layout, numbering, and finished floor elevations of the proposed residential buildings. Its primary purpose is to define the unit addressing scheme, building square footages, and spatial relationships between the structures, property boundaries, and existing site features like easements.

**Key values**:
*   Plan Scale: 1" = 20'
*   Building 1: 3,290 sf, FFE = 687.50 (Units 101-104)
*   Building 2: 4,830 sf, FFE = 685.50 (Units 201-206)
*   Building 3: 4,144 sf, FFE = 685.50 (Units 301-305)
*   Building 4: 4,144 sf, FFE = 685.50 (Units 401-405)
*   Building 5: 3,290 sf, FFE = 683.0 (Units 501-504)
*   Building 6: 3,290 sf, FFE = 683.0 (Units 601-604)
*   Building 7: 4,144 sf, FFE = 685.0 (Units 701-705)
*   Building 8: 4,997 sf, FFE = 685.50 (Units 801-806)
*   Benchmark #1 Elevation: 678.52' NAVD 88 (GEOID 18)
*   Benchmark #2 Elevation: 681.08' NAVD 88 (GEOID 18)
*   Tree Protection (CRZ) Mulch Requirement: 3-inch layer of hardwood mulch

**Content blocks on this sheet**:

*   **Block 1: drawing** — Main site addressing plan showing the townhome layout, individual unit locations, building dimensions, and property lines. Use VISION to examine the spatial layout of buildings, unit addressing sequences, finished floor elevations (FFEs), and locations of surrounding easements and utility infrastructure. 
*   **Block 2: notes** — Information regarding the primary elevation control points for the project. READ the block content for the exact benchmark elevations, datum (NAVD 88), and point descriptions.
*   **Block 6: text_block** — The legal description of the property being developed. READ the block content for the subdivision name, lot number, and recording information (Volume 73, Page 76).
*   **Block 3: notes** — Environmental and administrative disclaimers, including fencing installation near trees. READ the block content for hand-digging requirements and mulch specifications inside the Critical Root Zone (CRZ), as well as utility verification responsibilities.
*   **Blocks 4, 5: various** — Boilerplate and administrative details, including the Texas 811 "Call Before You Dig" logo and the Professional Engineer's seal. READ the block content for the engineer of record's license number (Jason K. Rodgers, 97881) and signature date.
