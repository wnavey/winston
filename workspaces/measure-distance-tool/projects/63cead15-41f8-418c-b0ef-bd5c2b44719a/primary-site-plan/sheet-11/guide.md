# Sheet 11 — Grading Plan

This sheet displays the detailed grading plan for the development site.

## Reading Guide

This sheet presents the Grading Plan for the Valley View Townhomes multi-family development located at 3759 Valley View Road, Austin, Texas. Its primary purpose is to detail existing and proposed topography, establish building finished floor elevations (FFEs), map storm drainage infrastructure, and indicate the location of retaining walls and utility easements across the site.

**Key values**:
*   **Scale**: 1" = 20'
*   **Benchmark 1**: Elevation = 678.52' NAVD 88
*   **Benchmark 2**: Elevation = 681.08' NAVD 88
*   **Bldg 1**: 3,290 sf | FFE = 687.50
*   **Bldg 2**: 4,830 sf | FFE = 685.50
*   **Bldg 3**: 4,144 sf | FFE = 685.50
*   **Bldg 4**: 4,144 sf | FFE = 685.50
*   **Bldg 5**: 3,290 sf | FFE = 683.00
*   **Bldg 6**: 3,290 sf | FFE = 683.00

*   **Level Landing Maximum Slope**: 2%

**Content blocks on this sheet**:
