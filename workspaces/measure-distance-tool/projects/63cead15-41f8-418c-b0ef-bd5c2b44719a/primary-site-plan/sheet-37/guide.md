# Sheet 37 — Landscape Details

Contains landscape details for tree planting, tree protection, and shrubs.

## Reading Guide

This sheet provides standard landscape detail drawings for the Valley View Townhomes project. It primarily contains City of Austin compliant specifications for tree planting, tree protection during construction, and general shrub planting guidelines.

**Key values**:
*   **Tree Protection Critical Root Zone (CRZ)**: Radius = 1ft per inch (12mm per mm) of trunk diameter.
*   **Tree Protection Mulch**: 150mm (6") depth inside the protection zone.
*   **Tree Protection Clearance**: Minimum 1.5m (5') necessary work space; if less, add boards strapped to trunk.
*   **Tree Planting Pit Size**: 3x the width of the rootball.
*   **Tree Planting Stakes**: 8' length black painted steel T-post, driven min. 18" below tree pit.
*   **Tree Planting Rootball**: Set level to grade or slightly above grade (1/2").
*   **Tree Trunk Support**: Arborbrace webbing allowing a maximum 2" movement in any direction.
*   **Planting Mulch (Trees & Shrubs)**: 3" depth organic wood mulch; for trees, keep mulch 6" away from the root crown.

**Content blocks on this sheet**:

*   **Block 1: diagram — City of Austin Tree Protection Detail**: Illustrates standard fencing and mulching requirements to protect existing trees during construction (Standard 610S-4).
