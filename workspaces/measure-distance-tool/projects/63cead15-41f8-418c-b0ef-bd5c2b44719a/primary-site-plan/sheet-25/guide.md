# Sheet 25 — Construction Details 4

Standard details, plan, and section views for fire line meters.

## Reading Guide

This sheet provides City of Austin standard construction details for a 6", 8", or 10" fire line meter vault installation for the Valley View Townhomes project. It includes a comprehensive plan layout, vertical cross-sections, a material schedule, and specifications for vault dimensions based on meter size.

**Key values**:
*   Applicable Meter Sizes: 6", 8", or 10"
*   Vault Dimensions (Inside): 8' x 12' (for 6" meter), 10' x 12' (for 8" meter), 10' x 15' (for 10" meter)
*   Access Hatch Size: 48" x 72"
*   Minimum Clearances: 18" clearance between vault wall and bypass piping/meter components
*   Gasket Specification: Full face 1/8" thick red rubber
*   Pipe Material: Ductile Iron Class 53
*   Fasteners: 5/8" diameter x 8" long stainless steel wedge-all anchors
*   City of Austin Standard Number: 512-AW-02 (Adopted 03/10/2025)

**Content blocks on this sheet**:

*   **Block 3**: drawing — Plan view of the pipe system layout within the concrete vault. Use VISION to examine component placement, pipe routing, and minimum horizontal dimensional clearances.
*   **Block 2**: diagram — Section A-A view showing longitudinal vertical elevation. Use VISION for final grade relationships, concrete pad locations, and support stand configurations.
*   **Block 1**: diagram — Section B-B view showing transverse vertical elevation. Use VISION for alternative structural details and vertical clearance perspectives.
*   **Block 6**: table — Vault Schedule. READ for exact inside vault dimensions and offset dimensions corresponding to the specific fire line meter size being installed.
*   **Block 7**: table — Fire Line Meter Material List. READ for specific component descriptions, sizes, material types, and approved City of Austin part designations (e.g., link-seal modular seals, dismantling joints).
*   **Block 4**: notes — General construction and installation notes. READ for material specifications on nuts/bolts, gaskets, bedding, encasement, and drainage slope requirements.
*   **Block 13**: text_block — "Use of This Standard". READ for stipulations regarding when a project-specific structural design is required versus when this standard can be directly applied.
*   **Blocks 5, 8, 9, 10, 11, 12, 14**: various — Boilerplate & Administrative. Contains the main title ("6", 8" AND 10" FIRE LINE METER"), standard identifier (512-AW-02), adoption date (03/10/2025), agency info (City of Austin Water), disclaimers, and the professional engineer's seal.
