# Sheet 33 — Canopy Impact Exhibit

Exhibits detailing tree canopy calculations and construction impact analysis.

## Reading Guide

This sheet presents canopy impact exhibits for four specific trees to be preserved on the Valley View Townhomes project site. Each exhibit includes a plan view showing the mapped tree canopy intersecting with proposed construction, a photograph of the existing tree, and calculations detailing the total canopy area and the square footage and percentage of construction overbuild. 

**Key values**:
*   Tree 4026H Canopy: Total Area = 3917 sqft; Construction Overbuild = 173.38 sqft (4.43%)
*   Tree 4019H Canopy: Total Area = 2545 sqft; Construction Overbuild = 52.39 sqft (2.06%)
*   Tree 4038H Canopy (Detail 2): Total Area = 1786 sqft; Construction Overbuild = 82.29 sqft (4.60%)
*   Tree 4034 Canopy (Detail 1, text labeled 4038H): Total Area = 1188 sqft; Construction Overbuild = 231.9 sqft (19.52%)
*   Overbuild offset: 4' (typical for all exhibits)
*   Drawing Scale: 1" = 10'-0"

**Content blocks on this sheet**:

*   **Block 1**: Plan drawing and calculations for Canopy Impact Tree 4026H. READ for precise canopy calculations; Use VISION to see the spatial relationship between the tree canopy, the 4' overbuild offset, and the proposed building and fence.
*   **Block 2**: Plan drawing and calculations for Canopy Impact Tree 4019H. READ for specific area calculations; Use VISION to assess the overlap with the proposed building and the adjacent "no posts in half CRZ" fence line.
*   **Block 3**: Plan drawing and calculations for Canopy Impact Tree 4034 (Note: The calculation text block incorrectly labels this as Tree 4038H). READ for exact calculations; Use VISION to examine the extensive canopy overlap shading relative to the proposed sidewalk, retaining wall, and building.
*   **Block 4**: Plan drawing and calculations for Canopy Impact Tree 4038H. READ for canopy calculations and the specific note regarding Tree 4039 ("to be mitigated in place"); Use VISION to observe the spatial overlap with the proposed driveway, curb, and transformer.
*   **Block 5**: Legend detailing symbology for canopy plans. READ to understand the symbols for actual tree canopies and existing canopy over proposed building (hatching).
*   **Block 6**: Project title block. READ for basic administrative details including the project name (Valley View Townhomes), owner (WM 41 Austin RE, LLC), and address.
