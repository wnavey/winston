# Project Review Form

A completed City of Austin form indicating applicable land development codes and site plan application details for the project.

## Sections

1. **General Information and Applicable Codes** (p. 1)
   This section identifies the project location, legal description, and establishes that the current Land Development Code applies to the project.
   File: `01-general-information-and-applicable-codes.md`
2. **Information Required for Vested Rights Review** (p. 1)
   This section outlines requirements for vested rights review and includes the proposed project land use, watershed details, and the property owner's signature.
   File: `02-information-required-for-vested-rights-review.md`
