# TIA Determination Worksheet

Completed worksheet determining that a traffic impact analysis is not required for the proposed site plan development.

## Sections

1. **Applicant and Project Information** (p. 1)
   Provides the location, applicant contact details, application type, and acknowledgment of the Street Impact Fee program.
   File: `01-applicant-and-project-information.md`
2. **Trip Generation and Roadway Data** (p. 1)
   Contains tables detailing the existing and proposed land uses, trip generation rates, and abutting roadways for the project.
   File: `02-trip-generation-and-roadway-data.md`
3. **TPW Staff Determination** (p. 2)
   Provides the official review determination from TPW staff, concluding that a full traffic impact analysis is not required.
   File: `03-tpw-staff-determination.md`
