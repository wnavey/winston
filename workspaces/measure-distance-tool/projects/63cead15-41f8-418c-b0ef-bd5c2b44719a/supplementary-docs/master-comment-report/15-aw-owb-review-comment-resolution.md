Comment Resolution Process:
You can submit a Comment Resolution Request if:
1. You have identified two or more comments in your Master Comment Report that conflict with each other; and
2. You do not believe that the comments can be satisfied.

Comment Resolution Requests can only be submitted and resolved between review cycles. They cannot be submitted while the site plan is in review. Use the Comment Resolution Request Web Form to submit your request.
