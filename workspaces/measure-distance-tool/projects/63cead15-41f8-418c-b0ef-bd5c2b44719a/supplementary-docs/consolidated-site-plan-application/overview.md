# Consolidated Site Plan Application

Completeness check submittal for a consolidated site plan permit application in the City of Austin.

## Sections

1. **Project Information** (pp. 1-2)
   Details the project type, name, street address, proposed development description, and legal deed references.
   File: `01-project-information.md`
2. **Contacts Information** (pp. 2-3)
   Provides contact details for the applicant, owner, engineer, and other professionals involved in the project.
   File: `02-contacts-information.md`
3. **Property Attributes** (pp. 3-4)
   Outlines jurisdictional boundaries, housing program participation, watershed details, and street/neighborhood plans for the site.
   File: `03-property-attributes.md`
4. **Application Assessment and Site Area** (p. 5)
   Contains traffic impact analysis requirements, site area calculations, existing/proposed zoning use tables, and impervious cover percentages.
   File: `04-application-assessment-and-site-area.md`
5. **Land Use, Waivers, and Arborist Review** (p. 6)
   Details compatibility standards, requested waivers or variances, and tree counts within and adjacent to the limits of construction.
   File: `05-land-use-waivers-and-arborist-review.md`
6. **Authorizations and Acknowledgments** (pp. 7-8)
   Contains applicant signatures for submittal verification, inspection authorization, and general acknowledgments regarding property restrictions.
   File: `06-authorizations-and-acknowledgments.md`
