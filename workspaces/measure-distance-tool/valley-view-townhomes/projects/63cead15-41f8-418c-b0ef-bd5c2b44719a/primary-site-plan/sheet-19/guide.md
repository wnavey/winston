# Sheet 19 — Utility Tap Plan

Utility tap plan showing proposed water and wastewater connections.

## Reading Guide

This sheet contains the Utility Tap Plan for the Valley View Townhomes project, detailing the layout and connection points for proposed water, wastewater, and storm drain lines across eight multi-family buildings. Its primary purpose is to define utility routing, drainage fixture unit (DFU) loads, pipe material specifications, and regulatory compliance notes for the site's wet utilities.

**Key values:**
*   Private domestic water branches: 2" HDPE service tubing
*   Private wastewater branches: 6" PVC at a minimum 2.0% slope
*   Pressure reducing valve (PRV) set pressure threshold: 65 psi
*   Number of private fire hydrants on site: 1
*   Trench depth requiring geologist inspection: Greater than 5 feet
*   Drainage Fixture Units (DFUs): 4Plex = 136 DFUs, 5Plex = 170 DFUs, 6Plex = 204 DFUs
*   Benchmark #1 Elevation: 678.52' (NAVD 88)
*   Benchmark #2 Elevation: 681.08' (NAVD 88)

**Content blocks on this sheet:**

*   **Block 2**: The main site plan diagram showing buildings (Bldg. 1-8), utility routing (water, wastewater, storm drain), lift stations, cleanouts, and site topography. Use VISION to examine the spatial layout, pipe routing, line lengths, and specific component locations.
*   **Block 1**: Legend defining the symbols and line types used for existing and proposed utilities (W, WW, RW, E, SD) in the main diagram. Use VISION to cross-reference symbols while reviewing Block 2.
*   **Block 13**: Utility notes specifying pipe materials and slopes for private domestic water and wastewater branches. READ for exact material sizes and installation standards.
*   **Block 7**: Drainage Fixture Unit Table breaking down the total DFU loads by building number and type (e.g., 4Plex, 5Plex, 6Plex). READ for specific sanitary load calculations.
*   **Block 17**: Benchmark data providing precise elevations and descriptions of vertical control points. READ for exact elevation values used for site grading and utility slopes.
*   **Block 10**: Water tap note outlining requirements for replacing existing Asbestos Cement (AC) pipe with Ductile Iron (DI) pipe and required hazardous disposal protocols. READ for regulatory compliance regarding existing AC lines.
*   **Block 11**: Special Services Division note mandating compliance with the Austin Fire Code for the site's private fire hydrant. READ for maintenance obligations and the exact private hydrant count.
*   **Block 5**: Technical note dictating the use of factory restrained joint pipes or mechanical joint restraint devices for all water line bends, tees, and valves. READ for specific structural requirements on water mains.
*   **Block 9**: PRV Note stipulating that any structure with water pressure at or above 65 psi must install a pressure reducing valve. READ for pressure management requirements.
*   **Block 19**: Geologist inspection requirement note triggered by the Void and Water Flow Mitigation Rule for deep trenching. READ for the specific trench depth threshold (5 feet).
*   **Blocks 3, 4, 6, 8, 12, 14, 15, 16, 18, 20**: various — Boilerplate & Administrative. Contains the project title block, engineering firm details, Texas 811 logo, legal description, disclaimers regarding utility locations, and a cross-reference to the landscape plan for trees.
