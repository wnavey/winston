# Sheet 32 — Tree List

This page provides a detailed list of surveyed trees.

## Reading Guide

This sheet contains the comprehensive Tree List for the Valley View Townhomes project. Its primary purpose is to inventory all surveyed trees on the site, detail their current condition, specify whether they will remain or be removed, and calculate the total required tree protection and tree mitigation in inches based on local codes.

**Key values**:
- Total Required Tree Protection: 672.00 inches
- Total Removed Trees: 306.00 inches
- Total Required Tree Mitigation: 217.00 inches
- Total Surveyed Heritage Trees (24" & UP): 212 inches
- Total Surveyed ECM Appendix F Trees (19" - 23.9"): 99 inches
- Total Surveyed ECM Appendix F Trees (8" - 18.9"): 295 inches
- Tree Survey Date: 03/28/2025

**Content blocks on this sheet**:

READ the block content for the line-item details of every tree, including its tag number, diameter in inches, species, arborist-assessed condition, and mitigation status. Read the far-right and bottom rows for the exact calculations of required tree protection inches, removal inches, and mitigation inches categorized by tree type (Heritage, Non-Heritage, Appendix F, etc.).
