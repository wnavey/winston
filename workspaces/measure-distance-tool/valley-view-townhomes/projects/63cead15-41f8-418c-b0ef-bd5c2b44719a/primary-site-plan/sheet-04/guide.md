# Sheet 4 — Existing Conditions Survey

Topographic survey detailing existing structures, trees, and property boundaries.

## Reading Guide

This sheet contains the Boundary, Improvements, Topographic & Tree Survey representing the existing conditions for the Valley View Townhomes project. Its primary purpose is to document the baseline physical state of the site prior to development, detailing topographic contours, existing structures, property boundaries, easements, and a comprehensive tree inventory.

**Key values**:
* Existing Slab Finished Floor Elevation (F.F.E.): 686.8
* Survey Coordinate System: Texas Coordinate System of 1983 (NAD83) Central Zone, Grid
* Largest surveyed trees on site: 36" Hackberry (Tree #4028), 34" Live Oak (Tree #4042), and 28" Live Oaks/Hackberry (Trees #4000, #4025, #4026)
* Job Number: 20240953 
* Project Number: RJ3 70496

**Content blocks on this sheet**:

* **Block 1**: Main site plan drawing — Shows the existing property conditions including topographic contours, property lines, existing slabs, fences, utility lines, and surveyed tree locations (marked with '+' and ID numbers). Notable areas include "LOT 2 MECEY SUBDIVISION" and adjacent "VALLEY VIEW ROAD". Use VISION to examine the spatial layout, topographic contours, and physical site features.
* **Block 5**: Legend — Defines the symbols and abbreviations used throughout the site plan for pins, monuments, fences, utility lines (water, wastewater, electric), and easements. READ the block content for specific symbol definitions.
* **Block 12**: Tree Table — A schedule listing the cataloged trees found on the property, detailing their ID number (corresponding to the plan drawing), caliper size in inches, and species (e.g., Live Oak, Hackberry, Pecan). READ for exact values and species of specific trees.
* **Blocks 2, 4, 10**: Project and Title Blocks — Contains the project name (Valley View Townhomes), site address, sheet title (Existing Conditions Survey), and contact information for Bleyl Engineering and Sinclair Land Surveying. READ for project context and firm details.
* **Blocks 3, 6, 8**: Survey Data & Document Control — Contains the survey's bearing basis (NAD83), job/project numbers, sheet numbering (Sheet 4 of 39), and CAD/design routing information. READ for specific coordinate system references and document tracking numbers.
* **Blocks 7, 9, 11**: Boilerplate & Administrative — Contains surveyor certification notes, the Registered Professional Land Surveyor (Ryan T. Lenz) signature and state seal, and a list of Bleyl Engineering office locations. READ the block content for surveyor credentials, certification dates, and legal disclaimers.
