# Sheet 23 — Construction Details 2

Standard construction details for water infrastructure, valves, and fire hydrants.

## Reading Guide

This sheet contains "Construction Details 2" for the Valley View Townhomes project, specifically focusing on City of Austin standard details. It provides specifications, cross-sections, and installation procedures for typical gate valves (4"-16"), fire hydrant assemblies, and utility trenching with unfinished surfaces.

**Key values:**
*   **Gate Valves:**
    *   Clearance: 3" - 5"
    *   Concrete Block (for valves <12"): 16" x 16" x 4" minimum
    *   Concrete cradle: Minimum 2000 P.S.I., Class B
    *   Concrete pad patch: 3' x 3' minimum (Item 403S Class "A") with 5" minimum depth and #5 rebar at mid-depth.
    *   Total depth of asphalt + concrete: 9" minimum
    *   Stem extensions required when valves exceed 3' deep from finished grade; extension nut must be 12" - 18" from finished grade.
    *   Valve component weights: C7 Lid = 13 lbs, Reclaimed Lid = 15 lbs, C6 Frame = 23 lbs, Reclaimed Frame = 33 lbs, C5 Base = 76 lbs.
*   **Fire Hydrants:**
    *   Clearances: 3' around hydrant, minimum 18" from face of curb to steamer nozzle.
    *   Distance from ADA/pedestrian elements: Minimum 4' from ramps, strictly >6" from any sidewalk.
    *   Hydrant Bury Depth: 4' - 5'
    *   Drainage pit: 24" diameter and 12" deep below the hydrant bowl.
*   **Trenching (Unfinished Surface):**
    *   Minimum cover: 300 mm (12")
    *   Bedding envelope below pipe: 150 mm (6")
    *   Trench width: Pipe O.D. + 300 mm (12") minimum to Pipe O.D. + 600 mm (24") maximum.
