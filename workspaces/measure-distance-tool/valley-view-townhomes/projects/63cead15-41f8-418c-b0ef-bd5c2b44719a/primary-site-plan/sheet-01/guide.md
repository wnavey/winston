# Sheet 1 — Cover

Cover sheet containing project details, location map, and sheet index.

## Reading Guide

This is the cover sheet for the Valley View Townhomes site plan (SP-2025-0126C). It serves as the primary reference document for the project, containing the sheet index, site development data, fire department requirements, a location map, and required municipal compliance notes.

**Key values:**
*   Project Area: 2.16 Acres
*   Limits of Construction: 2.26 Acres
*   Total Residential Units: 39 units
*   Total Plan Sheets: 39 sheets
*   Fire Flow Demand (@ 20 psi): 3000 GPM (Reduced to 1500 GPM with sprinkler system)
*   Building Fire Area: 13,344 s.f.
*   Occupancy Classification: R3
*   Construction Classification: Type V-B
*   Sprinkler System Type: NFPA 13D
*   Private Hydrants: 1
*   Mapsco / City of Austin Grid: #614S / #G19

**Content blocks on this sheet:**

*   **Block 15:** text_block — Project title, address (3759 Valley View Road), and permit number (SP-2025-0126C). READ for core project identification.
*   **Block 4:** table — Site Development Data. READ for project team contact information, legal description, and exact acreage values. 
*   **Block 6:** table — Sheet List Table. READ to understand the structure of the 39-page drawing set and locate specific disciplines (grading, drainage, landscaping, etc.).
*   **Block 7:** table — Austin Fire Department requirements. READ for specific fire design codes, fire flow demands (in GPM), and building classification data.
*   **Blocks 1 & 30:** drawing & text_block — Project Location Map and associated scale/coordinate data. VISION for the spatial layout of the site relative to major cross streets (Manchaca, Clawson Rd, 290); READ Block 30 for Mapsco #614S and Grid #G19.
*   **Blocks 8 & 31:** text_block — Environmental status notes. READ to confirm the site is in the West Bouldin Creek Watershed, is outside the 100-year floodplain, and is not in the Edwards Aquifer zone.
*   **Blocks 16, 17, 25, 26, 27:** various — Project-specific requirements and waivers. READ for specific stipulations including private hydrant maintenance (Block 16), private biofiltration pond maintenance (Block 17), parkland dedication fees for 39 units (Block 25), a specific DCM waiver (Block 26), and Traffic Control Plan requirements (Block 27).
*   **Block 5:** table — Revisions/Corrections. READ to confirm no revisions have been logged yet.
*   **Blocks 2, 3, 9-14, 18-24, 28-29, 32, 33:** various — Boilerplate, Administrative Notes, and Seals. READ selectively if reviewing general contractor responsibilities, standard city ordinances (lead-free water, recycling, USTs), engineer certifications, liability disclaimers, or standard erosion control notes. Includes empty approval stamps and review tables.
