# Sheet 30 — Existing Tree Plan

Site plan displaying existing trees, protection measures, and care notes.

## Reading Guide

This sheet contains the Existing Tree Plan for the Valley View Townhomes project, detailing the layout of eight building structures amidst existing vegetation. Its primary purpose is to identify which trees will remain, which will be removed, and to outline the necessary tree protection measures and remedial care requirements during construction.

*   Bldg. 1: 3,290 sf, FFE = 688.50
*   Bldg. 2: 4,830 sf, FFE = 685.50

*   Bldg. 4: 4,144 sf, FFE = 685.0
*   Bldg. 5: 3,290 sf, FFE = 683.0
*   Bldg. 6: 3,290 sf, FFE = 683.0
*   Bldg. 7: 4,144 sf, FFE = 685.0
*   Bldg. 8: 4,997 sf, FFE = 685.50
*   Valley View Road right-of-way: 60' R.O.W.
*   Mulch depth for critical root zone protection: Minimum of 12 inches
*   Post-construction mulch depth reduction: 3 inches
*   Graphic scale: 1" = 20'-0"

**Content blocks on this sheet:**

*   **Block 1: drawing — Existing Tree Plan**
    Contains the main site plan showing townhome building footprints (Units 101-806), topographic contours, and tree locations. READ for exact building square footages and Finished Floor Elevations (FFEs), and use VISION to examine the spatial layout of the buildings relative to the existing trees, property lines, and tree protection fencing.

*   **Block 5: notes — Key Notes**
    Acts as the visual legend for the tree symbols used on the main site plan (heritage trees, trees to remain, trees to be removed, and protection fencing). READ the block content to understand the symbol definitions, then use VISION to cross-reference these symbols on the Block 1 drawing.

*   **Block 3: notes — Special Construction Techniques**
    Outlines five specific techniques for protecting tree root zones during excavation, including root cutting, mulch requirements, and vapor barriers. READ the block content for exact excavation and root protection specifications required by the City Arborist. 

*   **Block 2: notes — Remedial Tree Care Notes**
    Details a six-point program for aeration and supplemental nutrients for trees impacted by construction areas. READ the block content for specific soil/foliar analysis rules, fertilization composition guidelines, and pre/post-construction treatment protocols.

*   **Blocks 4 & 6: various — Boilerplate & Administrative**
    Contains the title block, landscape architect information (Blu Fish Collaborative), project location details, professional seal, sheet number (27 of 35), north arrow, and scale bar. READ for general project administrative details and use VISION to verify drawing orientation and scale.
