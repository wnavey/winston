# Engineer's Summary Letter

An engineer's summary letter detailing existing conditions, proposed improvements, and utilities for the project site plan.

## Sections

1. **Header and Introduction** (p. 1)
   Document header, addressee, and introductory statement identifying the summary letter for the proposed townhome development.
   File: `01-header-and-introduction.md`
2. **General Information** (p. 1)
   Provides the site location details, including watershed, floodplain status, aquifer zone, and zoning information for the project.
   File: `02-general-information.md`
3. **Existing Conditions** (p. 1)
   Describes the current state of the site, noting existing impervious cover, drainage patterns, and easements.
   File: `03-existing-conditions.md`
4. **Proposed Project** (p. 1)
   Outlines the proposed construction of 39 townhomes, water quality controls, and a reduction in impervious cover.
   File: `04-proposed-project.md`
5. **Utilities** (p. 2)
   Details the planned water and wastewater connections for the project's eight buildings and includes the engineer's sign-off.
   File: `05-utilities.md`
