# Land Development Engineering Review

*Informational requirements for License Agreements, Encroachment Agreements, Easement Releases, and ROW Vacations.*

**CC Land Development Engineering** – Land Development Engineering

Comments below are Informational (website). License Agreements, Encroachment Agreements and Easement Releases are separate applications which should run concurrent with your development application. Please note that License Agreements (LA) and Encroachment Agreement (EA) require an AULCC submittal and review prior to LA and EA application submittals

A **License Agreement** is needed for items that will be temporarily placed within the City of Austin current or proposed Right of Way (ROW) or Easement(s) and shall be executed prior to issuance of the development permit. City Code Chapter 14-11 
➢ Contact LandManagement2@austintexas.gov for pre-submittal meetings as needed. Reference website for application requirements
➢ Current and proposed easements should be shown on all site plan sheets.
➢ Site Plan set is required to include License Agreement Plan Sheet and Landscape Sheets, and Irrigation Sheets if these appurtenances are proposed.
➢ Typical License Agreements include, but not limited to, awnings, canopies, benches, bike racks, trash receptacles, street trees, landscaping, irrigation, outdoor dining areas, and pedestrian lighting. (See website for list of most common appurtenance that we license.)

An **Encroachment Agreement** is needed for items that will be permanently placed within the City of Austin Right of Way (ROW) and shall be executed prior to issuance of the development permit. Encroachment Agreements require approval by City Council. City Code Chapter 14-11 
➢ Contact LandManagementROW@austintexas.gov for pre-submittal meetings as needed.
➢ Reference website for application requirements
➢ Typical items include, but not limited to, Sky Bridges, Balconies, Underground Parking Garages, etc..

For development applications needing City of Austin **Easement Releases** prior to approval. City Code Chapter 14-11
➢ Contact LandManagement@austintexas.gov for initial consultation as needed.
➢ Reference website for application requirements.

For development applications needing City of Austin **ROW Vacations** prior to approval. City Code Chapter 14-11
➢ Contact LandManagementROW@austintexas.gov for initial consultation as needed.
➢ Reference website for application requirements.
➢ City Council approval is required.
